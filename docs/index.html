Croissant Policy Profile

An additive policy layer for Croissant dataset descriptors. Croissant describes what a dataset is; it does not say what may be done with it. This profile lets a dataset declare the operations it admits and the conditions under which it admits them, so a gate in front of the data can permit or refuse a request from the descriptor alone and leave a record of what it checked.
