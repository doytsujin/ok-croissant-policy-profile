## Caveats that should not be glossed

- A repository being public is generally treated as "made available to the
  public" regardless of whether anyone accessed it. Zero measured access is a
  factual record, not a legal reset.
- GitHub emits a `PublicEvent` to its public timeline when a repository is made
  public, and third-party archives (GHArchive and similar) capture that event
  stream. The event — repository name, owner, description — is therefore very
  likely in a public archive permanently. Repository *contents* are not normally
  mirrored by those archives, but this cannot be asserted with certainty.
- Search-engine and other automated crawlers are not counted in GitHub's traffic
  figures.
